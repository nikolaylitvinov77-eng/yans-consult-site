# Сайт ЯНС Консалт

Сайт консультационной компании «ЯНС Консалт», созданный в Claude Design.

**Живая версия:** https://nikolaylitvinov77-eng.github.io/yans-consult-site/

## Структура

- `index.html` — главная страница сайта (для GitHub Pages)
- `Сайт ЯНС Консалт.dc.html` — главная страница (оригинал экспорта Claude Design)
- `Брошюры услуг ЯНС Консалт.dc.html` — страница с брошюрами услуг
- `Форма обращения ЯНС.dc.html` — форма обращения клиентов
- `Пиктограмма направления.dc.html` — компонент пиктограммы направления
- `doc-page.js`, `support.js`, `yans-directions.js` — скрипты страниц

Рабочие материалы проекта (документы, ТЗ) хранятся локально и в репозиторий не входят.
